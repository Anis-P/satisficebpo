NEXORA BPO SOLUTIONS - WEBSITE
==============================
Open index.html in any browser. Works offline (Google Map and fonts need internet).

HOW TO EDIT
- Text: open any .html file in Notepad / VS Code and change the words.
- Website name: search "Nexora" in all .html files and replace.
- Logo: replace images/logo.svg (and images/favicon.svg) with your own logo,
  keeping the same file name. For a PNG logo, save as images/logo.png and
  replace "logo.svg" with "logo.png" in the html files.
- Images: replace any file inside images/ using the SAME file name.
- Colors: open css/style.css and edit the variables at the top (:root).
- Phone / email / address: search and replace in the .html files.
- Forms: currently show a thank-you message. To receive emails, connect a
  form service (e.g. Formspree) by adding action="..." method="POST" to the <form>.
